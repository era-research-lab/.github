## About us

The **ERA Lab**, led by [Prof. Xiaomin Lin](https://xiaominlin.github.io/), develops
intelligent robotic systems for challenging, unstructured environments. Our research
spans computer vision, robot perception, multimodal learning, autonomous systems, and
embodied AI — with applications in **underwater robotics**, **field robotics**, and
**intelligent autonomy**.

## Research areas

| | |
|---|---|
| 🌊 **Underwater robot perception** | Perception and autonomy in turbid, GPS-denied marine environments |
| 🧊 **3D computer vision** | Multimodal 3D detection, reconstruction, and scene understanding |
| 🧩 **Multimodal learning** | Fusing heterogeneous sensors into robust representations |
| 🤖 **Embodied AI** | Closing the loop between perception, planning, and control |
| 🛰️ **Synthetic data & digital twins** | Simulation pipelines that bridge the sim-to-real gap |
| ⚡ **Edge AI & LLM reasoning** | Efficient on-board perception and high-level robot reasoning |
